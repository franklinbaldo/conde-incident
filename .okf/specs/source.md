# Tipo Source

Unidade documental original ou derivada. Exigir source_id, locator, provenance, verification_status, além de type/title/description. Registrar custódia, hash, URL, data de publicação e dependências quando disponíveis; ausência de cadeia não comprova independência.

A validação de metadados não certifica dados históricos nem premissas físicas.
